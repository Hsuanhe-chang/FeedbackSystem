# FeedbackSystem 畫面規格書總覽

> 系統名稱：意見回饋管理系統（FeedbackSystem）
> 資料庫：`Feedback_Test`（Server: ymmistest）
> 技術棧：ASP.NET Core MVC (.NET)、Bootstrap 5

---

## 畫面清單

| # | 畫面名稱 | 路由 | HTTP | 說明 |
|---|---------|------|------|------|
| 1 | [首頁](./01_首頁_Home_Index.md) | `/` | GET | 系統入口頁面 |
| 2 | [意見列表（後台）](./02_意見列表_Feedback_Index.md) | `/Feedback` | GET | 後台管理員查看所有意見，支援篩選與分頁 |
| 3 | [提交意見（前台）](./03_提交意見_Feedback_Create.md) | `/Feedback/Create` | GET / POST | 客戶填寫並提交新意見 |
| 4 | [意見詳情](./04_意見詳情_Feedback_Detail.md) | `/Feedback/Detail/{id}` | GET | 顯示意見完整內容、回覆串，並提供新增回覆表單 |
| 5 | [編輯意見（後台）](./05_編輯意見_Feedback_Edit.md) | `/Feedback/Edit/{id}` | GET / POST | 後台管理員修改意見狀態、內容與備註 |

## 共用元件

### Status（處理狀態）標籤顏色對照

| 值 | 文字 | Bootstrap Badge Class |
|----|------|-----------------------|
| 0 | 待處理 | `bg-secondary`（灰色） |
| 1 | 處理中 | `bg-primary`（藍色） |
| 2 | 已回覆 | `bg-success`（綠色） |
| 3 | 已關閉 | `bg-dark`（黑色） |

### Priority（優先等級）標籤顏色對照

| 值 | 文字 | Bootstrap Badge Class |
|----|------|-----------------------|
| 1 | 一般 | `bg-secondary`（灰色） |
| 2 | 重要 | `bg-warning text-dark`（橙色） |
| 3 | 緊急 | `bg-danger`（紅色） |

### ReplyType（回覆類型）

| 值 | 文字 | 對齊方向 | 底色 |
|----|------|---------|------|
| 0 | 客戶回覆 | 靠左 | 灰底（`bg-light`） |
| 1 | 官方回覆 | 靠右 | 淡藍底（`bg-primary bg-opacity-10`） |

## 資料關聯圖

```
Feedback（主表）
    ├── FeedbackId (PK, IDENTITY)
    ├── TrackingCode
    ├── CustomerName / CustomerEmail / CustomerPhone
    ├── Category / Subject / Content
    ├── Status (0~3) / Priority (1~3)
    ├── AdminNote（後台備註，不對客戶顯示）
    ├── LatestReplyContent / LatestReplyAt / ReplyCount（快取欄位，系統自動維護）
    └── CreatedAt / UpdatedAt

FeedbackReply（子表）
    ├── ReplyId (PK, IDENTITY)
    ├── FeedbackId (FK → Feedback.FeedbackId)
    ├── Content / ReplierName
    ├── ReplyType (0=客戶回覆, 1=官方回覆)
    ├── IsPublic (0=私密, 1=公開)
    └── CreatedAt
```
